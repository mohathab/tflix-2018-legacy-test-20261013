# TFlix 2018 Legacy Test

Experimental compatibility build of TFlix 2.0.5
for older Samsung Tizen televisions using Chromium 56.

Based on:
https://github.com/Zyrecx/TFlix

TFlix is created by Zyrecx and licensed under MIT.

This test build uses Vite's legacy-browser support
to generate compatibility JavaScript and polyfills.

This is an unofficial experimental build.

It has not been verified to work on actual television
hardware and may still require further compatibility fixes.

No subscriptions or streaming content are included.
